一码收首个桌面试用版，支持连接现有云端文件收集服务。

- Mac Apple Silicon / Intel、Windows x64、Linux x64 安装包。
- 原生保存文件、下载记录、断网重连、可配置 HTTPS 服务地址。
- 保留二维码提交、日期归档、30天保存、筛选打包、回收站和打印店收件。
- 公开仓库同时提供客户端与云端服务源码。

需要网络和兼容云端服务。使用本应用自己的用户名和密码注册登录，支持恢复密钥找回。桌面版不解除微信的网址拦截。

Mac采用ad-hoc签名，尚未完成Apple Developer ID签名/公证；Windows尚无商业签名证书。请核对下载来源与SHA256校验和。
